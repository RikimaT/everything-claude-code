# ブリッジ進路分析システム

総合学習教室ブリッジの進路分析システム。生徒のテスト点数と中学校補正を使い、Vもし偏差値を推定して進学先を予測する。

## ファイル構成

```
career-analysis/
├── build_spreadsheet.py                    # .xlsx生成スクリプト
├── ブリッジ進路分析システム_新規シート.xlsx    # 生成済みExcelファイル
├── README.md
└── ocr/
    ├── ocr_vmoshi.py                       # V模試PDF読み取り（将来用）
    └── ocr_seiseki.py                      # 成績表PDF読み取り（将来用）
```

## Googleスプレッドシートへのインポート手順

### 1. アップロード

`ブリッジ進路分析システム_新規シート.xlsx` をGoogleドライブにアップロードし、Googleスプレッドシートで開く。

### 2. シートのコピー

以下の4シートを、既存の「ブリッジ進路分析システム_v6.xlsx」にコピーする:

1. **中学校補正マスタ** - 中学校ごとの学力補正係数
2. **換算マスタ** - 補正後5科合計→推定偏差値の変換テーブル
3. **テスト点数入力＆進学先予測** - メインの予測シート
4. **OCR読取データ** - OCR読み取りデータの蓄積用

コピー方法: シートタブを右クリック → 「別のスプレッドシートにコピー」→ 既存ファイルを選択

### 3. 参照範囲の確認

数式が以下の既存シートを参照している。シート名が一致しているか確認:

- `'高校別サマリー'` - 高校名と偏差値のVLOOKUP参照
- `'中学校補正マスタ'` - 補正係数のVLOOKUP参照
- `'換算マスタ'` - 5科合計→偏差値の変換参照

プルダウンの参照範囲（例: `'高校別サマリー'!$A$2:$A$19`）は、実際のデータ行数に合わせて調整が必要な場合がある。

### 4. データ入力

| 項目 | 対応 |
|------|------|
| 補正係数（中学校補正マスタ） | 稲枝中=1.00は入力済み。他は田中氏に確認後入力 |
| 換算テーブル（換算マスタ） | A列は昇順で入力すること（VLOOKUPの近似一致で必要） |

## スプレッドシートの使い方

### テスト点数入力＆進学先予測シート

1. A列に生徒名を入力
2. B列で学年を選択（プルダウン）
3. C列で中学校名を選択（プルダウン）
4. D〜H列に各教科の点数を入力（0〜100）
5. I列に5科合計が自動計算される
6. J列にVもし偏差値があれば入力（空欄可）
7. K〜M列で補正係数・補正後合計・推定偏差値が自動計算される
8. N列で志望校を選択（プルダウン）
9. O列に志望校の偏差値が自動表示される
10. P列に判定が自動表示される（A〜E判定、色分け付き）
11. Q〜S列に偏差値が近い高校が3校自動提示される

### 判定基準

| 判定 | 条件 | 色 |
|------|------|------|
| A判定（安全圏） | 推定偏差値 >= 志望校偏差値 + 3 | 青 |
| B判定（合格圏） | 推定偏差値 >= 志望校偏差値 + 1 | 緑 |
| C判定（ボーダー）| 推定偏差値 >= 志望校偏差値 - 1 | 黄 |
| D判定（努力圏） | 推定偏差値 >= 志望校偏差値 - 3 | 橙 |
| E判定（要再考） | 推定偏差値 < 志望校偏差値 - 3 | 赤 |

## OCRスクリプト（将来用）

### 前提条件

```bash
pip install pytesseract pdf2image Pillow
sudo apt install tesseract-ocr tesseract-ocr-jpn poppler-utils
```

### V模試PDFの読み取り

```bash
python ocr/ocr_vmoshi.py <PDF_PATH> --output result.csv
```

### 成績表PDFの読み取り（単体/一括）

```bash
# 単体
python ocr/ocr_seiseki.py <PDF_PATH> --output result.csv

# フォルダ一括
python ocr/ocr_seiseki.py <FOLDER_PATH> --batch --output result.csv
```

OCR結果は必ず田中氏に確認を取ってからスプレッドシートに入力すること。

## .xlsxの再生成

シート構造を変更したい場合:

```bash
python build_spreadsheet.py
```
