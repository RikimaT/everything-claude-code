# 戦略：エビデンスを「納得感」に変える設計図

## 1. ターゲット心理の把握
- **彦根市付近の小学生保護者**は、中学受験ブームと教育DXの狭間で「習い事のROI（投資対効果）」を厳しく見ている層。
- 不安の根は「AI時代に、計算ができるだけで本当に意味があるのか？」という疑念。
- 彼らが求めているのは「計算力」ではなく**「変化の激しい時代を生き抜く脳の土台」**。

## 2. 採用エビデンス（優先順位）
保護者の意思決定で最も「腹落ち」するのは下記2点。**「右脳活性化（漠然とした魅力）」だけでは弱い**ため、近年の神経科学・統計データで裏打ちする。

### ① 主軸：実行機能向上（Wang et al., 2017）
- **理由**：「判断力・計画力」は中学受験〜社会人まで一貫して求められる能力。fMRI研究という科学的権威が「単なる計算ドリル」との差別化に直結する。
- **訴求コピー**：「そろばんは、脳の"OS"をアップデートする。」

### ② 補強：非認知能力との統計的有意相関（1,720名調査）
- **理由**：保護者が本当に欲しいのは「折れない心」。N=1,720という規模感が「うちの子だけの話ではない」という安心感を生む。
- **訴求コピー**：「自己肯定感と忍耐力に、統計的有意な相関。」

※「右脳活性化（東大研究）」は、ビジュアル（脳が光る演出）の根拠として補助的に使用。

## 3. 「納得感」への変換ロジック
| フェーズ | 心理状態 | 仕掛け |
|---|---|---|
| 0–5秒 | 「またそろばん広告か」 | **常識の破壊**：「計算が速くなる、だけだと思っていませんか？」 |
| 5–20秒 | 「えっ、そうなの？」 | **科学的権威**：fMRI画像風CG＋論文出典テロップ（画面隅・小さく） |
| 20–27秒 | 「うちの子にも…」 | **地域性**：彦根城をバックに通う子どもの笑顔（ローカル親近感） |
| 27–30秒 | 「問い合わせよう」 | **行動喚起**：体験会CTA＋QR |

## 4. 差別化ブランディング
- キャッチ：**「脳のOSを、アップデートしよう。」**
- そろばん＝「アナログな伝統」というイメージを、**「最先端の認知科学に裏打ちされたブレイン・トレーニング」**へ反転。
- ロゴ脇に小さく `Brain OS Update Program` の英字を添える。

## 5. 信頼性の担保（微細注釈ルール）
- 画面右下、フォントサイズは本文の40%、白70%透過。
- エビデンス言及シーンの全カットで常時表示。
- 例：`※Wang et al., 2017 / 全国珠算教育連盟調査(N=1,720, 2022)に基づく`

## 6. 成果KPI（参考）
- 第一次：体験申込CVR 1.5%（ローカルTV/YouTube広告基準）
- 第二次：「OSアップデート」のブランド想起率 30%（半年後）
