# 自習室 NFC入退室管理システム

NFCタグ × Google Apps Script × スプレッドシートで構築する、自習室の入退室管理システムです。

---

## 1. DB設計（スプレッドシート構成）

### シート①：`入退室ログ`

| 列 | カラム名 | 内容 |
|---|---|---|
| A | タイムスタンプ | 打刻日時（Date型） |
| B | 生徒ID | 例: S001 |
| C | 氏名 | 例: 山田 太郎 |
| D | 区分 | 「入室」または「退室」 |
| E | 日付 | yyyy/MM/dd 形式 |
| F | 曜日 | 月〜日 |
| G | 時刻 | HH:mm:ss 形式 |

### シート②：`生徒マスタ`

| 列 | カラム名 | 内容 |
|---|---|---|
| A | 生徒ID | 一意のID（例: S001）|
| B | 氏名 | フルネーム |
| C | 保護者メールアドレス | 通知送信先 |
| D | 備考 | 任意（アレルギー等） |

> ヘッダー自動作成は `setupSheets()` 関数をGASエディタから手動実行することで行えます。

---

## 2. セットアップ手順

### ステップ1：Google スプレッドシートを作成

1. Google ドライブで新規スプレッドシートを作成
2. URLの `/d/` と `/edit` の間にある文字列をコピー（これが `SPREADSHEET_ID`）

### ステップ2：GASプロジェクトを作成

1. スプレッドシートのメニュー → **拡張機能** → **Apps Script** を開く
2. エディタに `Code.gs` の内容を貼り付ける
3. `+` ボタンで **HTML ファイル** を追加し、ファイル名を `index` にして `index.html` の内容を貼り付ける
4. `Code.gs` 冒頭の `CONFIG` を設定：
   ```javascript
   SPREADSHEET_ID: 'ここにスプレッドシートIDを貼り付け',
   ADMIN_EMAIL:    'あなたの管理者メールアドレス',
   ```

### ステップ3：シートを初期化

1. GASエディタで関数リストから `setupSheets` を選択して **実行**
2. 権限を確認・許可する
3. スプレッドシートにヘッダーとサンプルデータが自動作成される
4. `生徒マスタ` シートに実際の生徒情報を入力する

### ステップ4：Webアプリとしてデプロイ

1. GASエディタ右上の **「デプロイ」→「新しいデプロイ」** をクリック
2. 種類: **「ウェブアプリ」** を選択
3. 以下の設定にする：
   - 説明: 自習室入退室システム（任意）
   - **次のユーザーとして実行：「自分（your@email.com）」**
   - **アクセスできるユーザー：「全員」**
4. **「デプロイ」** をクリック → 表示されたURLをコピーして保管する
5. 権限を再度確認・許可する

> ⚠️ `Code.gs` を変更した場合は「デプロイを管理」→「編集」→バージョンを「新バージョン」にして再デプロイが必要です。

## 3. NFCタグの設定

### 必要アプリ（無料）
- Android: **NFC Tools** または **TagWriter by NXP**
- iPhone (iOS14以降): **NFC Tools** (App Store)

### 書き込み手順

1. アプリを開き「書き込み」→「レコードを追加」→「URL / URI」を選択
2. デプロイで取得したGASウェブアプリのURLを入力
3. NFCタグ（シール）にスマホを近づけて書き込む
4. 書き込み完了後、スマホをタグにかざすとブラウザで打刻画面が自動的に開く

### タグ選定のポイント
- **NTAG213** (180バイト)：URLが短ければ十分、安価（1枚 ~50円）
- **NTAG215** (504バイト)：長いURLも余裕、推奨
- シール型タグは貼り付けやすく、机・ドア・壁に設置可能

---

## 4. システムフロー

```
スマホをNFCタグにかざす
        ↓
ブラウザが打刻URLを開く
        ↓
【初回のみ】生徒ID入力 → LocalStorageに保存
        ↓
「入室」または「退室」ボタンをタップ
        ↓
GASバックエンド (doPost) がリクエストを受信
        ↓
① 生徒マスタで生徒情報を検索
② 入退室ログシートに記録
③ 保護者・管理者へHTMLメール送信
        ↓
打刻結果を画面にフィードバック表示
```

---

## 5. トラブルシューティング

| 症状 | 対処 |
|---|---|
| 「生徒IDが見つかりません」 | 生徒マスタシートのA列のIDと入力値が一致しているか確認 |
| メールが届かない | GmailのGASアクセス権限を確認、迷惑メールフォルダを確認 |
| 「スクリプトエラー」 | `SPREADSHEET_ID` の設定値を確認 |
| NFCタグを読み取れない | iPhone はNFC対応(XS以降)か確認。設定→コントロールセンターにNFCを追加 |
| 変更が反映されない | GASを「新バージョン」で再デプロイしたか確認 |

---

## 6. カスタマイズのヒント

- **部屋番号を複数運用**: NFCタグごとにURLパラメータ (`?room=A`) を付け、ログシートに部屋列を追加
- **遅刻チェック**: ログ記録時に時刻判定ロジックを追加し、メール件名を変える
- **Slack通知**: GmailApp の代わりに UrlFetchApp でSlack Webhook に投げる
- **集計ダッシュボード**: 別シートにSUMIF/COUNTIF関数で在室中生徒数を集計
